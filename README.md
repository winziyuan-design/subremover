# subremover — 手机端本地去字幕/去水印

目标：完全在手机本地（不走服务器）去掉视频里的字幕、固定水印、动态水印，效果尽量接近云端小程序，做到手机能做到的极限。

## 目录
- `app/`：安卓 App 源码（com.chealert.subremover，当前 0.2.0：PP-OCRv3 文字检测 + 前后帧传播 + LaMa 单帧修补）。模型和 so 库未提交。
- `sttn/`：电脑端研究流程：STTN 视频修复（researchmm/STTN，MIT）+ 字幕/固定水印/动态水印检测掩码、ONNX/MNN 导出、性能测试。主入口 `pipe.py`。
- `proto/`：早期原型。

## 现状（样例 a.mp4，28.5 s，1080×1920）
- 字幕、固定水印、动态水印都能稳定识别并去掉，抽查 150 帧无残字。
- 不足：纹理复杂处（玻璃、海报、碗、包装袋）补出来偏糊、有格子感；明显不如小程序。
- 速度：STTN 每次推理（10 帧 × 1 区域）电脑 CPU 约 9 s，全片约 55 min；手机 CPU 估计 70–120 min。0.2.0 手机实测 5 分 28 秒。

## STTN 本身的问题
1. 固定 432×240 低分辨率工作，放大回原图必糊。
2. 固定方块切分 + 注意力，方块间信息交流少 → 格子状涂抹（FuseFormer 论文指出）。
3. 没有光流，只靠注意力找参考内容，运动时易糊（E2FGVI 加光流后明显改善）。
4. 训练用随机/物体掩码，没见过字幕这种细长白字带阴影。

## 优化方向（不改 STTN 权重，先做到极限）
1. **原分辨率切块**：裁出的区域不再缩到 432×240，而是按原分辨率切成多个 432×240 小块（重叠 + 羽化拼接），消除缩放糊。
2. **光流搬运真实背景（ProPainter 思路，自写）**：用 DIS 光流 + 前后一致性检查，把相邻帧中露出的真实背景像素搬进掩码；只有从未露出的像素才交给 STTN。
3. **高低频融合**：STTN 输出做低频底，高频细节取自搬运的真实像素。
4. **掩码精准化**：字幕笔画 + 阴影 + 相邻检测帧并集；动态水印跟踪；固定水印多帧持久性检测。
5. **提速**：无字帧跳过；只修文字实际包围盒；同一裁块内合并多区域；FP16 模型（34 MB）；流式解码不全帧驻留内存。
6. **手机推理**：MNN（OpenCL/Vulkan）或 ONNX Runtime（NNAPI/XNNPACK）跑 GPU，实测选最快。

## 下一阶段（如果上面仍不够）
- 自己训练字幕专用的轻量视频修复模型：在干净视频上叠加随机中文字幕/水印自动生成无限训练数据（原视频即标准答案）；结构参考 STTN/FuseFormer/E2FGVI：原分辨率、软切分、光流引导特征传播。需要租 GPU 训练，训好后仍在手机本地运行。
- 不考虑：ProPainter（非商用协议、太重）、扩散类模型（太重）。
